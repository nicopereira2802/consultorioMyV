# Frontend Client

Interfaz de usuario del sistema web, desarrollada como una Single Page Application (SPA) utilizando React y empaquetada con Vite para un rendimiento óptimo.

## 🛠️ Tecnologías Utilizadas
- React 18
- Vite
- JavaScript (ES6+)

## 🚀 Inicialización Rápida

1. Abre una terminal en este directorio (`/frontend`).
2. Instala las dependencias necesarias:
## npm install
3. Inicia el servidor de desarrollo:
## npm run dev

La aplicación estará disponible en tu navegador, usualmente en `http://localhost:5173`.
